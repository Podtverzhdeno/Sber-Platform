## Локальные команды воспроизведения

```bash
node "Apple UI kit/04-web-reference/verify-library.mjs"
python3 "Apple UI kit/04-web-reference/validate-svg-library.py"
python3 "Apple UI kit/advanced-cases/validate-advanced.py"
node "Apple UI kit/08-component-packs/verify.mjs"
python3 "Apple UI kit/scripts/verify_reference_pack.py"
python3 "Apple UI kit/scripts/audit_source_bundle.py"
python3 "Apple UI kit/scripts/audit_reference_links.py"
python3 "Apple UI kit/scripts/verify_impulse_crosswalk.py"
python3 -m unittest discover -s "Apple UI kit/scripts" -p "test_*.py" -v
node "Apple UI kit/react-reference/verify.mjs"
```

**Важно:** source crosswalk хранит исторические SHA файлов IMPULSE. Несовпадение SHA по умолчанию — предупреждение об изменениях и основание для повторной ревизии, а не предложение откатить исходник. Режим `--strict-sha` намеренно отдельный.

## Чего библиотека не утверждает

1. **Нельзя гарантировать 1:1 нативный Liquid Glass через CSS/SVG.** Системные refraction/lighting/dynamic rendering Apple не полностью воспроизводимы обычным браузером.
2. **Нет подтверждения точных размеров и внутренней структуры Apple Figma/Sketch UI kits.** Нужно открыть соответствующий оригинал, записать frame ID, платформу, версию, компонент, вариант, размеры, opacity, типографику, движения и сохранить разрешённый источник измерений.
3. **Нельзя считать пройденным визуальный pixel diff**, пока не получены эталонные и implementation скриншоты одинакового размера/масштаба/темы/контента; инструменты `08-component-packs/compare.html` и `04-web-reference/compare-screenshots.py` доступны, но сам факт выполнения измерения здесь не заявляется.
4. **Нет production UI интеграции** в этом наборе. Переход в React frontend требует отдельных PR с проверками API, RBAC, роутов, событий, доступности, тестов и визуальной регрессии.
5. **В репозитории нет лицензированных Figma/Sketch архивов, SF Symbols или шрифтов Apple**, намеренно — официальные ссылки и условия использования см. [Apple Design Resources](https://developer.apple.com/design/resources/) и [LICENSE](../05-legal-and-sources/LICENSING.md). Внешние Apple-hosted изображения могут быть показаны по ссылкам, но не зеркалируются в Git.
