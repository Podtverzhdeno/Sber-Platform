# Asset provenance and redistribution safety

This repository folder intentionally contains **no Apple licensed files**. Its HTML/CSS/JS was authored for Impulse and is not an exported Apple Figma UI kit.

## Materials to obtain directly from Apple
- iOS/iPadOS and macOS UI kits: https://developer.apple.com/design/resources/
- Official SF Symbols application and symbol resources: https://developer.apple.com/sf-symbols/
- San Francisco system fonts: https://developer.apple.com/fonts/

Read the current agreements on each resource page before commercial use, redistribution or derivatives. Linking to an original resource is not the same as obtaining permission to mirror its file into a public GitHub repository.

## Do not commit without rights verification
- SF Pro, SF Compact, SF Mono font files.
- Apple-provided Sketch/Figma source binaries or exported symbol artwork.
- Apple hardware UI mockup templates, photographs, marketing renderings, system screenshot compilations.
- Third-party community UI kits represented as official Apple resources.

## Open browser rendering
The gallery relies on local CSS, browser system font stack and text glyphs. It does not import fonts, images, SF Symbols, npm modules or external scripts. This allows it to be a safe reference/testbed when disconnected.
