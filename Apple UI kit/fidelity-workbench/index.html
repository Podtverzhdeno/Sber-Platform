Что нужно для проверки 1:1

01

Единая геометрия

Viewport, DPR, zoom, шрифты, локаль, тема и состояние UI должны совпадать. Нельзя подгонять размеры ради красивого сравнения.

02

Официальный источник

Получите разрешённый исходник через Apple Design Resources и запишите точную версию, платформу и frame.

03

Проверка поведения

Низкая визуальная ошибка не доказывает корректность API, доступности, RBAC, действий, focus и сохранения состояния.
