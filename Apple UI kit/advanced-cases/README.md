# Дополнительные сценарии Apple UI для Impulse (17–26)

10 новых папок; каждая содержит **2 масштабируемых SVG** (светлая и тёмная тема), описание ограничений и ссылку на соответствующий официальный раздел Apple HIG.

**Не официальный UI Kit:** SVG — самостоятельные визуальные концепты Impulse. Apple Figma/Sketch kits и их оригинальные слои остаются по [официальной ссылке](https://developer.apple.com/design/resources/). Подлинная 1:1 точность не подтверждена и требует отдельного измерения.
