## Recommended workflow
1. Choose a specific source and Apple 27 Figma/Sketch component frame.
2. Read the category notes, inspect official frame/light/dark/state and record exact measurements.
3. Compare the preview with Impulse-specific approved screenshot rather than blindly copying these invented vectors.
4. Implement HTML/React behavior; run source-backed pixel-diff and interactive QA.
5. Document native-vs-web deviations, licensing and reviewer approval.
