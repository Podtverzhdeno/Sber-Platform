IMPULSE · Apple UI kit / independent QA utility

Локальное сравнение скриншотов

Изображения обрабатываются только в браузере; ничего не отправляется на сервер. Этот инструмент помогает измерить отличия, но сам по себе не доказывает совпадение с официальным Apple Figma/Sketch. Используйте только материалы, на сравнение которых у вас есть право.

1. Исходное изображение и веб-реализация

Выберите два изображения одинаковой ширины и высоты.

Для корректного пиксельного сравнения нужны одинаковые размеры, масштаб браузера, устройство, шрифт, тема, состояние и расположение. По умолчанию каждый канал RGBA сравнивается с допуском 16; отклонение любого канала больше допуска помечает пиксель. Это алгоритмическое правило, а не официальный допуск Apple.

2. Результаты

Размер—
Пикселей с отличиями—
Доля отличий—
MAE / RGBA—

MAE — среднее абсолютное отличие RGBA-каналов, от 0 до 255. Доля отличий зависит от заданного допуска; прозрачность включена в расчёт. Метрики не учитывают семантику, права на изображения и корректность поведения компонентов.

Режим просмотра

Тепловая карта различий

Красный: отличие выше допуска. Прозрачный: совпадающие каналы в пределах заданного допуска. Ровно два сравниваемых изображения; совмещения и масштабирования алгоритм не выполняет.

Локальный веб-инструмент Impulse, не разработан Apple. Не содержит Apple UI kit, шрифтов, SF Symbols или изображений Apple. Проверка исходных кадров и состояния — см. родительский протокол.
