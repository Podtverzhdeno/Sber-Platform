# Лицензии и границы использования материалов Apple

## Критически важно для IMPULSE как веб-продукта

Apple Design Resources License (опубликована Apple, дата документа 2023-06-21, перепроверьте актуальность в Figma перед использованием):
https://developer.apple.com/support/downloads/terms/apple-design-resources/Apple-Design-Resources-License-20230621-English.pdf

По разделам 2A–2C лицензия ограничивает использование UI kit созданием макетов интерфейсов продуктов **только для платформ Apple**; прямо ограничивает использование для не-Apple ОС, embedding ресурсов в продукты и несанкционированную перепубликацию/переупаковку. Этот файл — краткое справочное изложение, **не юридическое заключение**.

Следовательно, для кроссплатформенного React-сайта:
1. **Да:** давать ссылки на Apple HIG, официальный Figma/Sketch оригинал и изучать принципы визуального языка.
2. **Да:** самостоятельно программировать UI-паттерны и авторские CSS/React-компоненты, проводя независимую проверку прав на результат.
3. **Не размещать:** оригинальные Figma/Sketch наборы, экспортированные PNG/SVG из них, системные иконки, SF Symbols и фирменные изображения Apple непосредственно в публичном git-репозитории без отдельного права.
4. **Не использовать:** SF Pro как самостоятельно размещаемый webfont без надлежащего разрешения. У San Francisco отдельная лицензия: https://developer.apple.com/fonts/
5. **Не делать:** бренд IMPULSE похожим на официальное приложение Apple/продукт Apple, использовать Apple logos как логотип сервиса.
6. **Для native iOS/macOS:** конкретные условия могут отличаться; изучите текущие соглашения и используйте предусмотренные системой компоненты.
7. **Учёт сторонних ассетов:** для каждого изображения/иконки в будущем нужна запись original URL, license, author, redistribution conditions.

Референсное оформление, создаваемое командой для IMPULSE, — это **не исходники Apple**. CSS-эквивалент размытия не идентичен нативному стеклу Apple, поэтому не называйте его «official Liquid Glass engine».

## Откуда взяты ограничения
- Apple Design Resources Agreement, пп. 2A, 2B, 2C.
- Apple Fonts: отдельные условия.
- Figma Help: при подключении официального Apple UI kit требуется принять EULA.
