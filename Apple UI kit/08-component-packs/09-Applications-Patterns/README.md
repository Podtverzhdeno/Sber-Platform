# 09 · Apple applications as behavior references

These are examples of **interaction patterns**, not permission to reproduce branded screens, copy protected screenshots or replace the approved Impulse visual reference.

| Apple product pattern | What to study | Impulse capability |
|---|---|---|
| Mail | three-pane inbox, category list, message detail | messages and project discussions |
| Messages | conversation list, grouped bubbles, composer | team chat and AI Buddy |
| Notes | folders, tags, document content, inspector | coursework and evidence |
| Reminders | smart views, scoped due items, list navigation | participant tasks and mentor queue |
| System Settings | grouped preferences and quiet separators | profile/settings |
| Photos | content-first chrome, adaptive toolbars | portfolio/assets |
| Finder | sidebar, browser, inspector, Quick Look concept | project and artifacts workspace |
