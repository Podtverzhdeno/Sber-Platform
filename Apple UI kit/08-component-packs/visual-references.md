# Внешние визуальные референсы · Apple official

Этот файл содержит **ссылки** на оригинальные визуальные примеры Apple, а не загруженные изображения. Нельзя представлять их как локальный Apple UI kit. Прямые исходные Figma/Sketch файлы соответствующих платформ находятся в [reference-manifest.json](./reference-manifest.json).

## Liquid Glass / iOS Photos navigation (2025 source)

Источник: [Apple Newsroom — iOS 26 Photos](https://www.apple.com/in/newsroom/2025/06/apple-elevates-the-iphone-experience-with-ios-26/).

![Официальный пример навигации Photos iOS 26 — изображение загружается с сайта Apple](https://www.apple.com/newsroom/videos/2025/autoplay/06/apple-elevates-the-iphone-experience-with-ios-26/apple-wwdc25-ios-26-liquid-glass-photos-app/posters/Apple-WWDC25-iOS-26-Liquid-Glass-Photos-app-250609.jpg)

Сопоставлять: content behind controls, tab morphology, visual contrast, bottom-safe insets. **Это iOS 26, не нормативный набор iOS 27.** Для новой версии используйте точный Figma kit iOS 27.

## macOS Tahoe / pane and toolbar (2025 source)

Источник: [Apple macOS Tahoe official product announcement](https://www.apple.com/newsroom/2025/06/macos-tahoe-26-makes-the-mac-more-capable-productive-and-intelligent-than-ever/).

![Официальный пример интерфейса macOS Tahoe 26 — изображение загружается с сайта Apple](https://www.apple.com/newsroom/images/2025/06/macos-tahoe-26-makes-the-mac-more-capable-productive-and-intelligent-than-ever/article/Apple-WWDC25-macOS-Tahoe-26-Apple-Intelligence-Shortcuts-Notes-250609_big.jpg.large_2x.jpg)

Сопоставлять: window rounding, depth layering, toolbar spacing, stable content surface. **Это 2025/macOS 26**, для точных компонентов 2026 нужна macOS 27 Figma/Sketch.
