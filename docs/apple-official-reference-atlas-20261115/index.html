03 / QUALITY GATE

Четыре условия точности

01 · SOURCE

Найти точный фрейм

Открыть UI Kit 27 в Figma/Sketch. Зафиксировать реальную платформу, версию, компонент, variant/state и node ID.

02 · MEASURE

Измерить геометрию

Frame, bounding boxes, padding, baseline, радиусы, материалы, тени, цвета и осознанно выбранные состояния.

03 · IMPLEMENT

Сохранить контракт

Переносить в семантические React-компоненты, не подменяя API, маршруты, RBAC, доступность и собственный дизайн Impulse.

04 · VERIFY

Сравнить и принять

Скриншот одинакового DPR/viewport, diff и независимое ревью на точном SHA. Для native Liquid Glass отмечать ограничения браузера.
