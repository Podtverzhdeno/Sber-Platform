## Исторические источники (после P0)

1. **`01-originals-user/`** — четыре оригинальных скриншота от пользователя; главный источник формы компонентов и композиции. Не подменять сгенерированными изображениями.
2. **`02-pixel-dashboard/`** — утверждённый тёмно-синий Impulse: `image(3).png` как визуальный эталон 1422×803, `impulse_pixel_reference.html` как HTML/CSS-источник геометрии, `impulse_pixel_blue.png`, `impulse_pixel_light.png`, `impulse_pixel_midnight.png` для трёх тем, `impulse_wave_840_q50.webp` как фон. Темы и элементы проверять по парам изображение + HTML, а не только по CSS проекта.
3. **`03-apple-calm-concepts/`** — ранее созданные концепты и рендеры в стилях Apple/calm/Liquid Glass, включая сравнение 4 вариантов. Это дополнительные варианты, не пользовательские оригиналы.
4. **`04-design-kits/`** — исходные Sketch, DMG, ZIP и XD с компонентами/паттернами; применять только с учётом разрешений, платформы и прав на активы. Apple kits не являются нативными React-компонентами.
5. **`05-reference-research/`** — извлечённые инвентари компонентов, разметок и UX-наблюдения, документ о CJM.
6. **`06-state-and-QA/`** — скриншоты состояния действующего Impulse, снимки Playwright и пользовательские иллюстрации (`image(5).png`). Они показывают то, **что реализовано**, и не заменяют желаемый референс.

## Безопасность интерпретации

- Числа, роль, имена, аватар, названия курсов и показатели из референсных изображений — демонстрационные. В production использовать данные API и права пользователя.
- Liquid Glass — прежде всего слой навигации и управления; постоянные информативные карточки должны сохранять читабельность.
- Для «попиксельно» сравнивать действующую сборку и референс **при одинаковом viewport, масштабе, Device Pixel Ratio и шрифтах**. Успешная сборка и отдельные Playwright тесты сами по себе не означают pixel-perfect.
- Проверять дизайн по официальным материалам [Apple Design Resources](https://developer.apple.com/design/resources/) и [HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials); это внешние ссылки, а не файлы внутри архива.

## Проверка состава

`manifest.json` фиксирует SHA-256 четырёх пользовательских оригиналов и четырёх рендеров из двух ZIP. Файлы, скопированные из библиотеки, сохраняют исходные байты и имена, без обработки изображений. Для больших бинарных UI Kits сервис управления библиотекой сообщил `succeeded`; при этом интерфейс просмотра папки может не индексировать неподдерживаемые форматы.
