## Normative interpretation

- `01`, `02`, `03` define information hierarchy and visual acceptance, subject to real data, current shell/tokens and accessibility.
- `04` defines the idea of stage planning only. Production uses the compact horizontal stages from `01` and MUST NOT add its «Итог» block.
- `92%` is task-to-trajectory match, never completion or probability of acceptance.
- “После задачи” is a forecast requiring an approved model, not a granted skill.
- Before accepted assignment every stage is plan-only; factual progress belongs to assignment/checkpoints.
- Numbers, names, companies, dates, mentor, rewards and portfolio benefits in PNG are synthetic until backed by authoritative API fields.
