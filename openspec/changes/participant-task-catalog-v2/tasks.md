## Coordination rules

- Agent MUST complete repository/claim preflight and create one atomic claim per assigned task or explicitly declared contiguous bundle.

## Definition of Done

- Cards, list and conditions modal match the approved hierarchy; «Итог» is absent.
- Match is explainable relevance, forecast remains potential, pre-assignment stages remain a plan.
- Cards/list use one ordered projection and preserve filters/selection/navigation.
- Current terms are explicitly accepted; apply is server-authorized and idempotent.
- Viewing/bookmarking/applying grants no verified skill, grade, reward, certificate or portfolio fact.
- Core CJM works without AI and handles local failures without blanking the route.
- API/RBAC, component, E2E, accessibility, performance and visual checks pass with review evidence.
- Reviewer, not developer, approves handoff and marks checkboxes.
