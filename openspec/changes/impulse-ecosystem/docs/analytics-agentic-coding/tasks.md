# tasks.md — Реализация аналитики Agentic Coding, сертификации и Skill Passport

**Назначение:** исполнимый план для команды разработчиков/ИИ coding-agent, связанный с `spec.md` и `competency_anchors.md`. **Не отмечать задачу выполненной**, пока нет работающего кода, теста и ревью результата. Все API-path, помеченные proposed, ещё предстоит реализовать.

**Источник истины:** corporate L1 PDF + TXT matrix + published rule registry. Контракт уровня Impulse должен сосуществовать со старой `базовый/уверенный` шкалой, а не переписывать её.

**Особо критично:** C-01..C-05 (разногласия матриц), граница student vs employee, real evidence vs прогноз, уровень навыка vs сертификация vs грейд.

## Definition of Done (общий для каждой задачи)

- Изменение протестировано: unit + API contract + frontend component/Playwright для UI.
- Данные со значением «неизвестно» не превращаются в ноль; иллюстративные значения не появляются в production.
- Нет несанкционированных данных или корпоративного L1 у студентов.
- Проверяются источники, версии, точные правила, provenance и состояние интеграции.
- Сохраняется существующая продуктовая аналитика и Skill Passport/credentials.
