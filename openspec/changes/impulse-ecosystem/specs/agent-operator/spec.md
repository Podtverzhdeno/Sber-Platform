# Spec Delta

## Purpose

Определяет объяснимый AI-триаж операционной очереди и поиск внешних дублей без автоматической верификации достижений или изменения доменных данных.

## ADDED Requirements

### Requirement: Приоритет очереди
Помощник оператора SHALL предлагать порядок дел на основании сроков, риска и числа затронутых объектов, а оператор SHALL видеть причину.

#### Scenario: Выплата и событие
- **WHEN** в очереди есть сбой выплаты и новая заявка о событии
- **THEN** помощник показывает прозрачные основания приоритета и позволяет оператору изменить порядок

### Requirement: Проверка дубля по источнику
Помощник SHALL сравнивать provider ID, external ID и другие допустимые признаки и SHALL не сливать профили только по ФИО.

#### Scenario: Тёзки
- **WHEN** два человека имеют одинаковое имя, но разные внешние ID
- **THEN** автоматического объединения и начисления трофея нет

### Requirement: Рекомендация без верификации
Результат агента SHALL оставаться предложением, пока уполномоченный оператор не проверит источник и не запишет решение.

#### Scenario: Победитель МАЯКОВ
- **WHEN** агент нашёл возможный список победителей
- **THEN** участнику не выдаётся трофей до проверки привязки личности и источника человеком

### Requirement: Устаревшее дело
Решение SHALL проверять версию дела; устаревшее предложение SHALL обновляться перед применением.

#### Scenario: Источник исправлен
- **WHEN** организатор отзывает запись до решения оператора
- **THEN** прежнее предложение нельзя подтвердить, а оператор видит новую версию

### Requirement: Безопасное исправление
Помощник SHALL показывать зависимые баллы, трофеи и документы для возможной коррекции, но SHALL не менять их без доменной процедуры.

#### Scenario: Отзыв победы
- **WHEN** источник отозвал результат после выдачи диплома
- **THEN** оператор видит затронутые записи и запускает проверяемое исправление с журналом

### Requirement: Качество агентной очереди
Панель SHALL собирать обратную связь оператора о ложных и полезных предложениях для оценки агента.

#### Scenario: Ложный дубль
- **WHEN** оператор отклоняет предположение о дубле
- **THEN** причина связывается с run и попадает в набор анализа качества после допустимой обработки данных
